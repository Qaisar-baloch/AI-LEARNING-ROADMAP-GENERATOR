# AI Learning Roadmap Generator

A multi-model AI pipeline that designs, critiques, and improves personalized learning roadmaps — turning a learner's profile into a structured, week-by-week curriculum with a built-in quality review loop.

Built as part of the **Pak Angels, HEC-NCEAC Generative & Agentic AI Training** program (Cohort 11, Aug 23 – Oct 10, 2026), organized by **PEC, NCEAC-HEC, iCodeGuru, and Aspire Pakistan**, under the initiative *"Building Pakistan's AI-Driven Knowledge Economy."*

**Live demo:** [huggingface.co/spaces/qaisar50850/AI-LEARNING-ROADMAP-GENERATOR](https://huggingface.co/spaces/qaisar50850/AI-LEARNING-ROADMAP-GENERATOR)

## What it does

You describe your domain, current skill level, weekly time budget, goal, and deadline. The app then:

1. **Generates** a full learning roadmap (Google Gemini) — prerequisites, week-by-week topics, projects, and a final capstone, structured as validated JSON.
2. **Reviews** that roadmap (Groq, `openai/gpt-oss-20b`) — an independent model critiques it for realistic pacing, prerequisite ordering, and goal alignment, and scores it out of 100.
3. **Improves** the roadmap (Gemini again) using that review's feedback, if it wasn't accepted outright.

The result: a roadmap that's been generated by one model and critically reviewed by a second, different model — closer to how a real curriculum gets peer-reviewed than a single one-shot generation.

## Why two models

Using Groq as an independent reviewer of Gemini's own output catches problems a single model tends to miss when grading itself — unrealistic weekly workloads, topics taught before their prerequisites, or scope that doesn't actually serve the learner's stated goal. It's a small "generate → critique → revise" loop rather than a single-pass generation.

## Tech stack

- **Gemini API** (`google-genai`) — roadmap generation & improvement, structured output via Pydantic schemas
- **Groq API** — independent roadmap review, structured JSON output
- **Pydantic** — schema validation for every model response (`UserProfile`, `Roadmap`, `Week`, `Topic`, `RoadmapReview`)
- **Gradio** — the web UI
- **Hugging Face Spaces** — hosting, deployed via a GitHub Actions workflow that auto-pushes on every commit to `main`

## Architecture

```
UserProfile
     │
     ▼
generate_roadmap()  ──▶  Gemini  ──▶  Roadmap (validated JSON)
     │
     ▼
review_roadmap()    ──▶  Groq    ──▶  RoadmapReview (score + feedback)
     │
     ▼
 is_acceptable? ──No──▶ improve_roadmap() ──▶ Gemini ──▶ improved Roadmap
     │
    Yes
     │
     ▼
  Final roadmap rendered in the UI
```

## Running it locally

```bash
git clone https://github.com/Qaisar-baloch/AI-LEARNING-ROADMAP-GENERATOR.git
cd AI-LEARNING-ROADMAP-GENERATOR
pip install -r requirements.txt

export GEMINI_API_KEY=your_key_here
export GROQ_API_KEY=your_key_here

python app.py
```

## Deployment

This app auto-deploys to Hugging Face Spaces via `.github/workflows/deploy.yml` on every push to `main`. API keys are stored as Space secrets (`GEMINI_API_KEY`, `GROQ_API_KEY`), never committed to the repo.
